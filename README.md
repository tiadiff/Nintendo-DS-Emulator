# DSZ
A modern Nintendo DS emulator frontend in C# utilizing Libretro.

## Features
- Nintendo DS emulation powered by melonDS libretro core.
- Dynamic fast-forward capabilities (2x, 3x, 4x, Uncapped).
- Touch screen support.
- Fully translated to English.
- Modern C# WinForms UI.

## Requirements
- .NET 10.0 (or matching runtime)
- Windows OS

## Building
Use `dotnet build -c Release` to build the frontend.
